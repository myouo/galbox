# galbox-sdk

TypeScript visual novel SDK: synchronous Core, Pixi WebGL2/Canvas stage, DOM text, Web Audio, IndexedDB and optional React UI. Includes stateful operations, synthetic save adapters, diagnostics and portable backups.

Public entries: `galbox-sdk` / `player`, `protocol`, `core`, `port-kit`, `react`, `testing`, `save-bridge`, `diagnostics`, `backups`, `release`, `settings`, `react/style.css`.

```ts
import { createPlayer, createHttpProvider } from 'galbox-sdk/player';
const program: unknown = await (await fetch('./program.json')).json();
const player = await createPlayer({
  program, provider: createHttpProvider(program, new URL('./', location.href).href),
  mount: document.querySelector<HTMLElement>('#stage')!, saveCompatibilitySeries: '1',
});
// Call from a user gesture (audio policy).
await player.start();
await player.save('quick');
await player.load('quick');
player.dispose();
```

Provide a positioned 16:9 mount. `createPlayer` prepares and verifies all assets before returning. Subscribe to `getSnapshot()` for immutable detached views; use prompt-bound `input` or `step` actions. React's `DefaultUI` supplies controls, choices, menus and history; import `galbox-sdk/react/style.css` and use a `.galbox-player` wrapper with a `.stage` mount. Host text is DOM. Input actions require both the prompt number and current view epoch.

Source values: bool/string/checked i32, checked i64, bit-encoded f64, null and bounded ordered collections. Stage effects, fixed all-success groups and WAV/MP3/Ogg Vorbis/Opus audio (mono/stereo). Legacy `audio.play` acknowledges startup; new `audio.track` completes only on natural end and supports explicit `audio.wait`. Loops and active audio use declared replay/stop restore policy. No exact sample-position restore. Finite opaque VP8 WebM clips and activated timed/hotspot prompts are supported; unknown source formats remain rejected. Registered operations support isolated invocation state and explicit full ABI migration.

Typed expressions are available from `port-kit`: `expr`, `assignExpression`, `branchExpression`, `templatePage`, `randomI32`. The current bool/i32/string AST supports checked arithmetic, scoped/profile queries, short-circuit conditions and bounded strings without eval. Templates persist evaluated text and source identity; restore does not recompute old text. `ProgramBuilder.rng(seed)` declares a fixed lcg32@1 stream; `rngFromHost()` uses explicit initial `CoreOptions.rngSeed`, or Web Player crypto entropy. Snapshots retain complete RNG state/draw count; restore never samples again or guesses a missing seed. Additional numeric/collection operators are documented below. Expression depth/node and string bounds are enforced by real factories/linker/runtime.

Snapshots contain narrative state; current durable profile is retained on load. Save success means IndexedDB transaction completion. Revision conflicts require an explicit discard/reload decision. `discardAndLoad` is that explicit resolution; normal load never silently merges nonmonotonic values. `dispose` releases this player's resources and does not cancel already committed storage transactions. Borrowed Store implementations remain caller-owned.

The WebGL Host draws when the owned stage values change and on every new run epoch; text/profile-only updates still execute normally without redundant Pixi frames. Each submitted stage is flushed to the driver. Disposal destroys this instance's textures, renderer/context, audio and listeners, while preserving shared Pixi global pools. Initialization that completes after cancellation also destroys its newly allocated renderer before rejecting; no narrative, save format or public API changes are involved.

Original fixture and full development instructions are in the repository. This checkpoint does not certify compatibility with any commercial title.

The complete common GalGame feature target is still under construction; the existing alpha milestone does not mean flowcharts, save thumbnails or scripted UI are implemented. Common systems belong to the SDK, with authored content/themes/defaults supplied by the work.

`galbox-sdk/settings` supplies validated preferences and merge factories. `preferencesDefaults` configures authored defaults; stored player values take precedence. `await player.updatePreferences({audio:{master:.5,bgm:.4,voice:.8,sfx:.7},text:{intervalMs:16}})` persists and applies preferences independently of story profiles and snapshots. Volumes are 0..1; text interval is 0..200 ms (0 instant). Mixer uses script × role × scripted bus × optional BGM duck × master gain without changing Task.gain. The default settings UI includes these controls. Cross-instance CAS conflicts require `reloadPreferences()` before retrying; unknown commit outcomes are reconciled by reading. A committed operation finishing after disposal returns committed/disposed accurately. Legacy custom Stores may omit settings ports; persistent update then explicitly rejects. Story backups currently exclude preferences. Session-only `setVolume` remains available.

`galbox-sdk/release` constructs and verifies manifests bound to the canonical Program, frozen operation/binding identities, catalog, media facts and resource limits. Pass `release` to `createPlayer` for an explicit manifest; legacy callers receive a derived manifest after the same resource preparation. CLI projects publish `program.json.release.json` beside Program; source/port/policy edits require `assets build` before validation. Defaults: 16 MiB per encoded file, 32 MiB encoded total, 128 MiB estimated RGBA, 32 MiB decoded PCM, 4096 px image side and 30 s per WAV. Supported source profile: PNG, fixed-size self-contained SVG, mono/stereo PCM16 or float32 WAV, MPEG LayerIII MP3 and single-stream Ogg Vorbis/Opus; actual device decoding is checked separately. `signal` cancels initialization and disposes the instance. Compressed audio defaults to HTMLMediaElement on a verified private Blob URL; `playback: "element"` also selects this path for WAV. Element duration uses optional `maxMediaMs` (default 1 h) and remains bounded by encoded limits, without retaining full-track PCM in an AudioBuffer. This is progressive decoding after complete verified byte acquisition, not progressive network playback. Resource diagnostics distinguish encoded inventory, estimated texture storage, retained PCM and media element encoded bytes. Permanent audio failure leaves a committed activation pending; a fresh Host can resume it without repeating committed profile updates. Runtime WebGL loss pauses the session; GPU recreation is explicit.

`await player.exportBackup()` captures all durable profiles and current/previous slot revisions after flushing progress. Save the current narrative position first if needed. Restore using `player.prepareBackupRestore(unknown)` then `await player.commitBackupRestore(plan)`; load the returned slot explicitly. Profile-only backups can explicitly start a new story via `player.start(restoredProfileId)` while retaining reading/unlock progress; the default UI lists these profiles across refresh. Restoration adds independent branches and preserves existing progress and activation authority. Packages are bounded to 1000000 JSON characters, 64 profiles and 128 slots; assets and original-save attachments are excluded. A lost commit reply is retried with the same plan. Cross-release restoration requires a `defineContentMigration` handle from `galbox-sdk/backups`; missing releases, invalid frames or incompatible text are rejected while preserving the source data.


Playback systems: `await player.setAuto(true)` waits for fully revealed text, actual non-looping voice completion and the configured active-time delay. Startup acknowledgements do not count as media completion. Auto stops at choices/end and pauses with menus, visibility or focus loss. `player.setFast(true/false)` emits ordinary text steps, stops at unread text unless `playback.skipUnread` is explicitly enabled, and never selects a choice or skips task/delay waits. Modes are transient: every load/new run starts manual, voice restores using its declared replay/stop policy.

Preferences wire v2 adds `playback: {autoDelayMs, skipUnread}`, `input: {advance,menu,auto,skip,quickSave,quickLoad}` arrays of supported physical key codes, and `display: {fontScale,windowOpacity}`. `normalizePreferences` / `normalizePreferencesRecord` upgrade complete v1 values without losing old settings or revision. Font scale is 0.75..1.5, background opacity 0..1, auto delay 0..60000 ms; duplicate cross-action keys are rejected. Input binds only to the focused instance stage/UI or `player.attachInput(element)`; editors and button activation retain normal behavior, held inputs clear on pause/rebind/load/focus loss. The default UI includes settings JSON import/export and reset. `player.exportPreferences()`, `await player.importPreferences(unknown)` and `await player.resetPreferences()` use the same persistent CAS path; reset uses authored defaults. Settings are independent of story backups. V2 preferences are not readable by old SDK binaries; the narrative snapshot ABI is unchanged. Structured text and finite ADV/NVL window layouts are described below; advanced typography and scripted UI remain separate tasks.

Structured text: `richPage(at,textId,revision,speaker,runs)` and `richText.text/ruby/br/pause/speed` from `port-kit` create real `text.rich` instructions. Text/speaker/Ruby reading accept strings or typed string expressions; expressions evaluate once and snapshots retain the evaluated runs. Safe style fields are color (#RRGGBB), bold/italic/underline/scale and a bounded fade/wave/shake effect. No source HTML or arbitrary CSS executes. New rich pages use fixed UAX29 Unicode17 graphemes via pinned unicode-segmenter 0.17.3; old page/template snapshots retain codepoint semantics. Runs cannot split a grapheme. Limits: 128 runs, 4096 UTF-16 text units, 256 per Ruby reading, 65536-character source signature. Builder declares text.rich/expressions capabilities.

Rich snapshots retain the source signature, token cursor, elapsed/remainder, reveal times and remaining inline pause. Restore reuses evaluated text, verifies visible/history origins and refuses missing/changed structured continuation without changing the old slot. Font speed preferences stay independently durable; applying the same interval preserves fractional time. Manual reveal completes the page, pauses and fades; a separate input marks read/advances. `isTextComplete` and `textUnitCount` from protocol operate on validated TextState and are shared by Core/Auto/skip. Inline pauses and incomplete fades block Auto; wave/shake do not. DOM prebuilds the whole rich page and updates visibility/effects using active time, so save/load reconstructs phase and pause/focus stops motion. Default history currently displays plain summaries while snapshots retain runs. ADV/NVL windows, themes and TrueType preparation are supplied by textLayout below; advanced typography and scripted UI remain follow-up tasks.

Text windows: `ProgramBuilder.textLayout(textLayout(initial,themes,windows))` and public `textTheme/textWindow/textFont` factories define bounded ADV/NVL windows in a 1280×720 logical frame. Standard `text.window.select/clear/visible/theme` instructions target validated IDs; the existing page/template/rich opcodes write to the active visible window. ADV replaces, NVL accumulates confirmed entries and requires explicit clear at its declared capacity (1..32). Global reading history survives clearing. Snapshots retain layout/font signature, window state and text origins; missing/changed state requires explicit migration, while legacy Programs without layouts keep their path. DOM windows scale with the mount and compose authored style with current player preferences. NVL scrolls to new entries; physical scroll positions are not narrative state.

Fonts: declare `font` assets with `font/ttf`. The normal provider/digest/encoded budget/release-facts path checks a bounded TrueType SFNT and the Web Host requires actual FontFace loading before activation. Each Host owns its registered font families and removes only those on disposal; late cancelled loads do not register. Explicit system fallback covers absent glyphs; loading success does not certify complete glyph coverage. WOFF/WOFF2, variable fonts, vertical text, kinsoku and automatic pagination remain unsupported. Font memory is not reported as measured decoded memory.

`PlayerOptions.textRenderer` is an optional public factory created after resources/fonts are ready. It receives `{mount,program,fontFamily}` and returns `{render,applyDisplayPreferences,dispose}`; `createDomTextRenderer` supplies the default implementation for wrapping. Program and render snapshots are isolated copies. The port owns presentation, cannot write Core state, and must clean up its resources. Player disposes a cancelled late factory result and never renders after disposal; a render failure after durable activation remains committed-pending for a fresh renderer to recover. This is a trusted TS extension contract, not a sandbox. Layout support does not imply the remaining flowchart, thumbnail, gallery or scripted UI tasks are complete.


Native data values: protocol exports i64(bigint|decimal), f64(number), f64Bits(hex), f64Number, nullValue(), list() and dict(). i64 is signed 64-bit canonical decimal; f64 wire value is big-endian 16-digit hex, preserving signed zero/infinities and canonicalizing NaN to 7ff8000000000000. Native inputs normalize case/NaN on owned copies, while opaque extension args/state keep their codec-defined JSON. Stored void/undefined/reference heaps are unsupported; returns=void still means no return value.

`expr` adds wide/real/nil, i64Binary/f64Binary and unary operators, explicit checked conversions, list/dict constructors and lookup/update/length/key operations. Lookups declare the expected result kind and reject missing/wrong-kind values; dictHas distinguishes absent keys from null. Lists allow 256 items, ordered dictionaries 64 unique keys (1..128 UTF-16 units), value trees 8 levels/1024 nodes. Updates copy values; dictionary replacement preserves order. Scalar templates format without locale or implicit collection coercion. IEEE NaN comparisons are false, signed zeros compare equal; i64 arithmetic checks overflow/zero division, f64 uses explicit basic ECMAScript IEEE behavior. `assignProfile` emits profile.expression. Builder infers values.extended; trusted operations may explicitly declare it with capability().

Snapshots, profile batches, recipes and portable backups retain canonical native data, including complete nested ownership and frozen retry payloads. Changed numeric slot kinds require explicit complete content migration, including previous cuts/profile/frames; original slots remain intact. Operation args/phase/wait changes still require full invocation migration. SDK schema validation keeps strict checks and uses failed-branch short-circuiting to bound recursive AST work; all semantic branches remain linked. This is an additive local alpha capability, not a guarantee that older binaries read the new types or that all source numeric semantics are implemented.

Stage effects: public port-kit factories stageImage/stageTween/stageFilter/stageCamera/stageFade/stageTransition/stageShake/stageStyle emit real bounded native instructions. Pose fields cover local position/opacity, scale/mirror, rotation/skew (degrees), pivot pixels and normalized anchors; style adds parent/z/visibility/rectangular clipping/basic blend modes. Core evaluates numeric expressions once, captures from/to/fields/duration/easing/source signature, and drives independent property channels. Conflicts reject or supersede from current values. task.cancel freezes, task.finish is explicit completion; all-success groups never treat cancellation/replacement as success. Relative motion is not re-evaluated on load.

Scene snapshots retain camera, blur/brightness/grayscale, image-only color overlay and deterministic shake, while object tasks retain affine/filter/crossfade state. Crossfade composes up to four premultiplied RGBA image layers, including transparent sources; replacing it continues the current mixture. Pixi Container/Sprite/Graphics/filter objects are rebuilt from the same state, with complete render caching and owned cleanup that preserves shared programs. Restore checks task source/progress/locks and graph closure before activation; corrupted/missing/new-incompatible state is refused while old slots remain. Legacy stage.put/animate share the locks and preserve their original path.

Limits: 128 objects, 256 retained tasks, eight hierarchy levels, four crossfade assets, 1..3600000 ms tasks, bounded transforms/filters. Nonrectangular masks, empty container nodes, arbitrary shaders, path/skeletal animation and other filters/transitions are not enabled. Effects target the image stage, not DOM text/UI. Intermediate filter textures are viewport-clipped with bounded padding; actual VRAM and large-work/60 FPS/cross-platform fidelity are not certified. Current original demo: ?demo=stage.

`audioTrack`, `audioFade`, `audioDuck` from `galbox-sdk/port-kit` build typed native instructions. Bus fades and voice duck envelopes use Core active time and survive saves; pause stops Core, AudioContext and element clocks. Loop points are milliseconds; element segment loops follow native timeupdate precision. New voice tracks bind a source recipe to the next text body. `await player.replayVoice()` restarts the current body's voice with a fresh request identity; the default UI exposes this control. Confirmation stops active body voice by default (`audio.policy` can disable it). Reveal alone does not. Replay never reopens an already ended logical result. Active stop-policy media waits/groups refuse saves; replay restores start at zero, with no physical position guarantee. AAC/MP4, chained/multiplex streams, arbitrary seek and history voice replay are outside this support set.

Graphics default to `graphics: {renderer: 'auto'}`: WebGL2 when available, otherwise Pixi Canvas2D. Use `graphics: {renderer: 'canvas'}` to force compatibility mode or `'webgl'` to require WebGL. Diagnostics expose `resources.renderer` and `graphicsFallback`; backend choice is device state and does not change snapshots/progress. Canvas supports the existing ADV/NVL/rich text/audio systems and basic sprites, affine transforms, hierarchy, rectangular clipping, camera, fade/shake and basic blend modes. Canvas supports the same finite blur/brightness/grayscale, isolated weighted crossfade, parent-group and camera filters through private offscreen surfaces. `maxCanvasBytes` optionally sets the composition budget (default 64 MiB, maximum 512 MiB); it counts the back buffer, filter stack and pixel workspaces separately from asset texture estimates. Exceeding it rejects a candidate before takeover or pauses a running session; it never skips effects. Blur uses native Canvas filtering or a premultiplied CPU Gaussian approximation when unavailable, with optical tolerance rather than identical GPU samples. A successful frame is copied from a private back buffer once; a failed composition retains the prior visible image. Running WebGL context loss still pauses the session; create a Canvas player and load a save to recover. All backends unavailable produces an explicit error.

`interactionPrompt` and `videoPlay` from `galbox-sdk/port-kit` add typed native prompts and blocking movie clips. Interaction enabled/deadline expressions resolve once; prepared prompts do not consume deadline time. The default UI reports bound input readiness through Player/coordinator; custom embedders call `activateInteraction(prompt, attempt, epoch)` after binding, then `chooseInteraction` or `pointInteraction` with the same identity. Restores preserve elapsed time and require new readiness; paused time is excluded, and a receipt at/after the deadline takes the authored timeout even if RAF callbacks are late. Disabled/outside/stale actions do not choose. Rectangles use the 1280x720 viewport, do not follow moving actors, and the highest enabled option wins overlaps.

Video supports one opaque VP8 WebM track with optional Opus/Vorbis mono/stereo audio, verified bytes/container facts and actual device preparation. It renders in the same Pixi canvas on WebGL and Canvas; native startup and natural end are distinct. `restore: 'replay'` recreates an active clip from zero; `'forbid'` rejects active manual saves/restores. Initial durable takeover has a controlled recovery path without duplicating profile commits. Skipping is explicit via `skipVideo` and never impersonates natural completion; `retryVideo` renews blocked requests. Pause/dispose stop owned elements/texture/nodes and ignore late callbacks; no global video ticker is used. Other audio is not implicitly stopped; video audio uses the sfx mix. No MP4/AAC/VP9, alpha/stereo video variants, loops, parallel movies or exact seek are claimed. Optional `maxVideoMs` defaults to 10 minutes within existing encoded/image budgets; decoder RAM is not measured.

For progressive HTTP playback declare `asset.transport={kind:'versioned-url',version}` on element audio/video, supply the verified release manifest, and explicitly pass `streaming:{integrity:'versioned-url'}`. `createHttpProvider` resolves typed streaming leases; Host independently checks conditional HEAD strong ETag/length/MIME/Range/immutable metadata before preparing or taking over and at new playback attempts. This is metadata-bound versioned URL integrity, not a completed client SHA-256 check; require an immutable version-serving origin contract. Default callers remain on full digest verification. Provider cancellation/lease ports are platform neutral and leases belong to individual Hosts; shared providers must retain other consumers. Snapshots bind the logical streaming catalog and never persist lease URLs or evidence. Resource diagnostics distinguish expected/digest-verified/versioned-url and inspected/manifest facts, verified bytes and remote declared bytes. Buffering or network failure never impersonates natural completion. No transparent reconnect, exact seek or chunk cryptographic verification is provided.
