# ADR0044：外部数据隔离与单值字段唯一性

状态：接受；任务E1-04，落实C01/C12。此变更修复输入校验边界，不增加剧情能力或wire字段。

## 支持集

JSON输入只接受有界的有限JSON数据树：对象来自普通或null原型，数组具有完整的自有连续索引。共享子对象分别复制，循环/访问器/非有限数值拒绝；普通字符串键（包括`__proto__`和非函数`toJSON`）按数据保留。

输入隔离从属性描述符复制已检查的值，不对调用方对象执行JSON序列化。隐藏的自有`toJSON`函数或访问器返回`INPUT_JSON`，数组继承的序列化钩子不执行。复制后的树独立计入原节点/深度/字符预算；不以readonly代替所有权，也不承诺同realm恶意Proxy的安全沙箱。

protobuf输入中的已知单值字段必须唯一，包括标量包装消息、普通消息/union的同一字段以及map条目内部的key/value。重复返回`PROTO_DUPLICATE`；IDL声明的repeated数组元素/map条目继续支持，重复map键仍按原校验拒绝，未知字段继续跳过。envelope的版本/类型错误保留原有错误码。

## 兼容边界

Schema、IDL字段编号、公开TS类型和合法编码器输出不变；原有SDK编码的快照、设置、Program和备份可继续读取。外部编码器若产生重复单值字段，必须在输入侧明确修正后再提交，不由SDK猜测应保留哪个值。不自动修改旧文件/存档，不增加隐式迁移。

## 验证

公开protocol/wire入口验证隐藏函数/访问器零调用、继承钩子隔离、稀疏数组、特殊键与别名隔离；原始protobuf字节验证重复字符串/布尔/整数/浮点与map项字段拒绝，同时保留IDL互通及全部原创Program往返。实际tarball消费者另验输入负例；完整单元/浏览器/存读档/性能结果见`docs/evidence/e1-04/REPORT.md`。
