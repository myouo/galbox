# ADR0074：正文窗口的权威透明度驱动

TextWindow可声明opacityObject，读取同一Snapshot中根舞台对象的position.alpha加motion.alpha（夹到0..1）作为整个DOM正文窗口的透明度。它只驱动透明度，不继承对象可见性、变换或父子树；允许使用不可见的透明图作为数值代理。以标准stage.pose/motion控制，时钟/签名/保存恢复仍由既有Core任务负责，不加入实例文字渲染器或Host回调。

活动正文必须能找到该根对象；保存恢复检查引用，移除被活动正文引用的对象在修改前拒绝。源字体、字形揭示、当前历史和已读不因淡化改变；截图包含同切点透明度。未声明时行为不变。新声明添加text.stage-opacity能力，旧SDK明确拒绝。窗口布局签名包含新声明，不暗中兼容变更后的布局。
