# ADR0064：按需发行版的驻留资源预算

旧ReleaseManifest在创建/验证时把整个资源目录加总后按启动工作集预算拒绝；整章即使按需加载也被当成一次全部预载。新增可选resourceScope=resident，缺省保留旧catalog预算语义。resident目录仍逐项验证种类、完整事实、去重、单文件/时长/图像边长及单项解码可容纳性；Host在每个实际候选工作集沿原resourceUsage执行聚合限制，AssetCache仍限制驻留与并发。

新字段进入正式Schema/Protobuf/发行指纹。明确声明resident才接受大目录，未识别字段的旧SDK拒绝。eager和chapter策略不能绕过工作集或缓存预算。没有提高设备内存限制、放宽快照，也不把资源目录全部预载。需发行版验证/篡改失败、旧模式聚合拒绝、resident单项超预算拒绝及真实按需浏览器。

实际测试同时发现ResourceLoader.known原先在驱逐后没有删除事实，累计历史目录会误报驻留超限。现在释放自己的资源记录才删除对应事实，重载记录不受旧dispose影响；先让Cache预算驱逐可释放项，再核验现有事实工作集，避免在驱逐之前误判。
