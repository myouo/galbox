# ADR0048：实例滚轮阅读与历史入口

2026-10-28。G1-04有限支持集。滚轮是Web输入适配，不改变Core指令、Snapshot或剧情保存点。

InputPreferences/PreferencesPatch.input新增可选wheel布尔字段（protobuf新字段7），缺省true；旧v2偏好规范化补默认，设置仍独立保存IndexedDB，不随旧剧情存档回写。公开设置API/默认设置页可关闭。

下滚提交现有step（先显完，下一独立手势推进）；上滚打开已有history系统页。仅playing且正文等待、无菜单/暂停/资源准备时受理。回放子Player仅可下滚；不允许从隔离回放打开主线历史。输入根由attachInput管理；菜单/表单/可编辑内容、原生滚动容器、横向滚动、修饰键/捏合缩放保留浏览器行为。

pixel/line/page统一为CSS像素（line=16，page=根高度，零高度附加根退回文档视口高度，单包上限960），累计48像素受理。一次滚动串只提交一次；连续包间隔不足220ms，包括方向反转与触控板惯性，不能再次显完/推进。首次包绑定epoch/prompt，后续包不得落到新切点。clear/失焦/配置/激活取消未完成手势且抑制余波，直到下一独立手势；不等待计时器后再提交剧情。阈值未到也阻止游戏表面默认页面滚动。多输入根冒泡只消费一次，detach/dispose清理监听。

真实SDK浏览器验证：三种单位、瞬显/推进分离、惯性/读档/菜单关闭余波、按钮/表单/原生滚动、双Player隔离、偏好刷新；独立实例接原历史背景/关闭资源和八语标签，显示SDK权威backlog，UI不伪造历史/跳PC。历史查看不同于章节回放；后者仍在F-01E。
