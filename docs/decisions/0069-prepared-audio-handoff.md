# ADR0069：版本音频的设备预备交接

实际公网慢网记录中，同一BGM在预备临时Audio被清理后，正式Audio又请求同一音频，产生重复启动等待。对versioned-url音频保留一个已完成元数据/首帧检查的暂停Audio，首个播放源独占取走；同资产的第二个同时播放源仍创建独立设备，绝不共享播放头。已取走设备由Playing清理，未取走设备由AssetCache淘汰/销毁清理；取用幂等且不可复活。

正式播放仍执行已有HTTP身份重验。保留相同src/crossOrigin避免重置预备缓冲；验证失败不播放旧缓冲。预备完成后使用metadata提示，不主动维持整曲预下载。流音频驻留估算新增完整编码字节加1MiB设备预留；前瞻与实际reserve使用相同计算，仍受原缓存上限。该估算不保证浏览器内部解码器/网络缓存的总RAM。视频沿现有准备路径，存档/wire ABI不变。

验收：真实元素第一次接手时已有可用帧、无src重置，同资产两个声部独立；未消费预备设备和活动设备都释放；版本变化/取消/离线不绕过校验；真实公网快速阅读重新验证并记录失败，不提高门槛或伪造媒体完成。
