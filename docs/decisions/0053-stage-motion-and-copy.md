# ADR0053：可恢复逐轴运动与图层复制

第一门要求多个并行逐轴运动与前后台页的同相复制。引入stage.motion能力：x/y独立有限关键帧（每轴最多32段）、初值与终值、linear/ease-in/ease-out、1..1000ms采样间隔；有限运动与无穷循环，循环公共周期有界。此支持集要求最终offset为0，基准位置由普通舞台姿态持有，运动offset可叠加，取消/完成回到基准，不隐式烘焙未知插件状态。

Task保存源签名、曲线、当前相位、逻辑身份、目标集合和冲突key；同key只替换指定目标，其它页的目标保留。stage.clone显式声明源→目标闭合子树映射，原子复制图像/姿态及运动相位，不创造第二个剧情流；源/目标仍在普通pose/filter动画中则明确拒绝。复制目标沿当前Program静态clone映射可达，恢复验证全部offset、冲突、来源和目标，不保存设备句柄。删除子树解除对应目标，最后目标删除才取消任务。原有stage任务ABI不变，新能力必须声明，旧实现拒绝。

Core按逻辑tick求值，Host只绘制Core的offset。任务/对象仍受256/128上限，原Canvas合成预算保持。需真实工厂、预算1/8/100、Unicode以外无作品语义、循环/不同轴周期、复制/替换/删除/取消、protobuf中途恢复、坏源/坏offset失败原子性以及两个图形后端验收；不以此代表整个第一门完成。
