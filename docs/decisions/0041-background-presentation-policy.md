# ADR0041：后台继续演出，退出自动阅读

依用户本轮修正：失焦/隐藏不应重开标题，OP与音乐继续。PlaybackPreferences新增可选backgroundPlayback='continue'|'pause'，默认continue。旧v1/v2偏好在规范化时补默认；既有快照与profile不写入此设置，不改Core/存档ABI。

continue模式保持已开始演出/媒体运行，并在进入后台前串行切manual、清按键/快进，回来不恢复Auto。普通正文/静态选项因此停在下个输入切点；作者声明的定时控制流仍按原逻辑。pause模式可显式冻结全部剧情/媒体，同样取消Auto。用户暂停、系统菜单、资源屏障与设备错误仍独立持有暂停原因，不由focus解除。已开始UI音效可自然结束，尚在准备的提示音取消；隐藏时不接收新的UI cue。

可见窗口由RAF驱动；隐藏且允许继续时用每实例250ms有界timer驱动同一个串行coordinator。隐藏时省略图像/正文/脚本UI绘制，回来按当前状态重建，禁止回到标题或重开Core。计时受浏览器节流/系统挂起限制，不承诺后台逐帧AV精度，也不绕过浏览器策略。timer与RAF互斥，dispose/暂停/恢复清理。

默认UI与公开偏好API可切策略，实例沿同一Schema/生成类型接入。验收包括旧设置补默认/protobuf/非法值、真实原曲时钟与OP/PC不重置、后台Auto关闭/不穿页、显式暂停不被focus解除、隐藏timer推进及清理、实包消费者。独立开发服务关闭HMR自动重载，避免源文件/转换产物更新把用户会话重建成标题；生产逻辑与手动刷新保持明确区别。
