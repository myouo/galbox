# ADR0050：跨稳定标签的有界预取

2026-10-29。真实作品将源标签编成无条件control.jump，旧balanced遇到标签即停止，不能提前准备下一段立绘。允许沿同函数的无条件jump跟随；每次仍至多128条（jump计入）、16资产和配置页数，visited拒绝循环。choice/条件分支/call/return/扩展等仍停止，不执行表达式、不改变PC/变量或猜选择。

Host仅在稳定函数/PC/等待种类变化时重算计划，不在每个文字揭示帧重复扫描整函数。更新预取批次时先取得新批次的引用，再撤销旧批次；共有在途资源不被先取消后重下。实际资源屏障、冻结旧画面、失败重试、LRU及明确用户暂停规则保持，不以跳过校验解决卡顿。

实例默认balanced/lookahead=2，demand仍可显式选；开始首屏仍按需，不把整个游戏目录变为eager。必须以原真实序章的HTTP请求/准备次数和音乐播放连续性对比验证，不凭策略名称宣布不卡顿。

预取计划也受资源事实预算约束：至多使用驻留预算一半及当前必需工作集外的余量，按声明图片/字体/PCM估算（含解码输入）选择前缀，避免密集OP将16张全屏图全部固定到超预算。HTTP provider的流URL保留版本参数但不再加入随机lease查询串，租约身份/取消仍独立，恢复与真实启动继续校验HEAD；相同不可变音乐可复用浏览器缓存。必须复验两个播放器和取消/版本变更，不能凭URL相同认为租约可合并。
