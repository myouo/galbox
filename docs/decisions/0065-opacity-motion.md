# ADR0065：可保存的不透明度关键帧

本作flash time是整个周期的总时长（count划分周期），wflash是一个整体可跳过等待。不能把它编成每半程另需点击的多个等待。stage.motion增加显式stage.motion.alpha能力，可使用alpha轴的-1..1加性偏移（与x/y相同有限曲线，终点0），每对象alpha偏移包络总和不超过1，最终绘制不透明度夹0..1。最多三个轴；默认x/y存档形状不变，alpha只在非零时写入派生motion，真实Task保留全曲线/相位。

镜像/复制/替换、恢复和有限组跳过沿既有生产路径；alpha不会被写回基准姿态，也不推移并行音乐时间。此支持集可表达白闪、多次脉冲与透明度变化，不新增特定作品opcode。需要中途protobuf恢复、完整单次跳过与Canvas/WebGL保存像素检查。
