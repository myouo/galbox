# ADR0055：有界粒子与精灵帧

第一门原雨/花瓣有完整可读TJS，提供确定参数而非VM。SDK引入stage.particles能力与stage.particles/start、stop有限指令（实际opcode为stage.particles与stage.particles.stop）：最多32粒子、每粒子1–2份镜像、1–4个父组、最多32样式、每样式1–32帧。每样式声明图片/整数crop帧、alpha、正向纵速范围、初始横向加速度、噪声与速度/加速度夹限、top/random-top回绕；配置含世界范围、固定步长16..1000ms、初始已生成数、生成概率、明确seed、浮点/截断坐标策略。

Core持有专用lcg32状态、所有粒子位置/速度/加速度/帧/生成状态与步进余量；不消耗剧情RNG，不用Host时钟或Math.random。镜像共享物理状态，通过不同父组控制页面可见性，前后台复制只复制父组可见标志，不重复采样。原作的随机参数分布与绘制顺序要对照；不声称复现原Math.random序列。源原档只存init/数量而重建粒子，SDK内部档明确保存当前相位。

StageObject/StageStyle增加可选frame矩形，Host以同一Pixi Texture source的frame视图绘制，Canvas同路径；不是第二图像引擎。裁切必须落在实际图片内，变体按需加载但当前任务用到的图和帧不可在播放时被丢弃。frame视图缓存有界，清理不销毁共享底图。

粒子生成对象由任务独占位置/图像/父组/裁切；普通stage修改/clone/remove不得破坏活任务，stop原子移除其对象。镜像对象计入原128对象/256任务及资源/Canvas预算，不提高活动上限。快照校验源配置/种类/图像/相位/状态范围/对象闭包，损坏失败不激活；程序定义/像素crop、固定步长分割一致、运行到回绕/延迟生成、暂停/两个后端/图文保存及恢复均需验收。
