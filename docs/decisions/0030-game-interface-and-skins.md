# ADR0030：默认游戏页面、作品皮肤与输入边界

状态：G6-02有限支持集已接受并验收，见../evidence/g6-02/REPORT.md。

1. Program.presentation为可选版本化作品界面配置，限定安全颜色/字号/圆角、系统字体或已声明font资源、标题背景/logo的image引用、有限标签和工具栏动作顺序。真实gamePresentation工厂与Schema/链接共同核验。没有presentation的既有作品保留经典DefaultUI布局；声明默认配置的新作品使用完整分屏布局，CLI新模板采用它。两者共用生产Player/系统组件，没有第二剧情执行器。
2. 新默认页面包括标题、系统菜单、保存、读取、历史、设置、流程图、鉴赏和数据管理（备份/导入/独立进度）。React只订阅Player和调用既有系统API。skin/页面状态不写Snapshot或Profile；改变外观不恢复旧设置，也不允许改变剧情/资源身份。Program完整release清单仍校验当前配置。
3. Player持有临时systemScreen并管理menu暂停原因；返回标题暂停当前故事，继续阅读回到同一运行；新开始需界面确认。页面切换先结束自身鉴赏/历史试听，取消/失权/未知head失败不伪称已恢复主线。导航请求有代次，过期关闭回调不能覆盖后续页面或新会话。不存在的流程图/鉴赏不能打开假页面。
4. 默认分屏面板在小视口使用有安全区间距的viewport对话框、可滚动内容和至少44px主要操作目标；桌面保持有界布局。Tab在当前页面/最内层确认框循环，Escape关闭当前可关闭页面，关闭后恢复有效的原焦点；不以全局监听器争抢另一实例焦点。后台故事和其他Player分别遵守自己的暂停。
5. 剧情/选项/互动/回放和脚本按钮共享有限按压规则：主指针身份、按下时的语义身份、移动阈值、释放命中；滚动/取消/跨控件松手/第二指针不能产生选择。键盘过滤repeat并保留按下身份；系统对话框中的按键不触发背后的剧情热键。原生表单控件继续遵循浏览器输入/IME与已有Core校验。
6. 页面组合沿正式存档/历史/流程图/鉴赏组件扩展展开/分页展示，保存和读取仍经原Player屏障。触控屏幕模拟、键盘、真实IndexedDB/Canvas/打包消费为本轮证据；不把模拟视口称为移动真机认证。G7另做综合/规模/性能门槛，N/F仍需真实资料。

补充显示边界：完整GameUI下的窄视口主表单按作者控件顺序重排并展开；独立嵌入/回放仍在本容器内。纵向图文捕获按比例容纳到既定320×180，不裁掉视口外形。资源目录/执行定义未变时，纯皮肤修改不影响Snapshot；增删资源仍按既有迁移约束。
