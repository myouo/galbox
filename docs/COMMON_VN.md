# 通用 GalGame 完整功能目标

用户已明确：目标是能由正式 SDK 承担常见 GalGame 的表现和系统能力。M0–M5/H1 只是有限 alpha 底座，不代表常用功能已经齐备；缺 N/F 资料仅阻塞真实适配，不能阻塞通用功能。

## 职责

| 内容 | SDK 提供 | 作品实例提供 |
| --- | --- | --- |
| 剧情/数据 | 类型化表达式、调用/分支、确定性随机、等待与完整恢复 | 剧情 Program、变量定义、分支规则与文本/节点身份 |
| 正文/文本框 | 富文本/Ruby、揭示与效果状态、ADV/NVL/多窗口、布局和 renderer 接口 | 字体、文本、样式/主题、窗口配置、局部效果声明 |
| 舞台/媒体 | 变换/转场/滤镜/并行任务、音视频播放与恢复策略 | 图片/音视频、轨道/循环/演出参数与素材映射 |
| 存档 | 统一捕获切点、正文+舞台缩略图、原子槽位/元数据、自动/快速/手动管理 | 槽位策略、版式、作品禁存规则 |
| 流程图/鉴赏 | 节点访问/解锁/合法重入、CG/音乐/场景回放与持久解锁 | 节点图、标题/封面/关联资源、解锁表达式和入口 |
| 设置/游戏 UI | 持久偏好、分轨音量、文字速度、自动/快进/输入；完整默认屏幕与脚本控件 | 默认值、皮肤、布局、菜单项目/控件声明和事件绑定 |
| 特殊原作行为 | 正式类型化扩展、完整 invocation/状态迁移与失败机制 | 特殊机制实现、原版 codec/mapping 与真实参照 |

Core 只管影响剧情/可恢复逻辑的状态与规则；Host 实现 DOM/Pixi/Web Audio/设备效果；runtime 串行协调；SDK systems/UI/storage 承担通用设置、存读档、流程图/鉴赏组件。系统默认实现必须可用，可替换外观/端口。React 不直接改 PC，实例不重复写存档、流程图访问或控件恢复内核。

## 门槛和顺序

任务唯一状态在 tasks.json。G0 定义目标、现有值族表达式/RNG 及后续浮点/集合扩展；G1 设置/自动阅读/输入；G2 正文与文本框；G3 舞台/媒体/交互；G4 图文存档/回溯；G5 流程图/鉴赏；G6 剧本 UI 和完整默认界面；G7 用原创作品覆盖全部通用功能与独立安装。最终两作 M6 另依赖 G7 和 N/F 真实认证。

G1-01 的正式持久设置、主/BGM/语音/音效音量、文字间隔已完成；G1-02 在同一系统补入 auto/skip、按键映射、显示辅助及偏好迁移/导入导出。其它设置与系统不因存在“扩展点”而计为支持。后续每种能力都须有 Schema/工厂、实际 Core/Host 或系统路径、UI、保存恢复/生命周期规则和反例。用 CSS/React 手写某界面只证明可定制，不证明 SDK 已有该通用功能。

## 三类状态

作品内容状态（窗口/文字效果/按钮等待/图访问）进 Snapshot 或剧情 profile；玩家偏好独立持久化，旧档不得回写旧设置；实例主题/资源/节点/控件定义属于版本化作品配置。平台设备状态重新探测，不随旧档假定恢复。截图必须绑定保存逻辑切点，不能把只有 Pixi 的截图冒充包含 DOM 正文的完整画面。

SDK 提供声明式默认组件、Builder 和策略；作品实例选择与组合它们。未实现的 G 任务保持 todo/in_progress，有限 alpha 的历史 done 仍只说明其原支持集通过。当前通用功能总体未完成。

G0-02 已实现现有 bool/i32/string 表达式与完整 RNG/插值保存恢复，G0-03 数据族仍未完成。G1-01 的基础持久设置已可用；G1-02 自动/快进/输入/显示辅助已落地，完整规则和验证见 PLAYBACK.md 与 evidence/g1-02；G2-01 结构化正文/Ruby/有限文字效果已实现，G2-02 的 NVL/多文本框/主题布局及其它后续任务仍未实现。各阶段完成不扩大到未验收的能力。
