# 真实作品与发行阶段所需输入

这些输入不阻塞标准 SDK 和原创 fixture。不要为了关闭任务而猜测它们。

## 首个真实迁移实验

可以现在接收一个真实作品的小章节，不必等待全部通用功能完成，也不必先提供整作。优先有源码或可读脚本、能在原环境继续运行的作品。先告知作品名称、具体版本/语言/补丁、原引擎（知道时填写）及本机资料路径；仅有图片/可执行文件不足以还原剧情控制流。

第一轮最小切片：

- 一小章的原始脚本及其调用到的脚本，含一个选项和两条短路线；保留变量、调用和返回的上下文。
- 对应背景/立绘/字体，以及实际用到的声音或动画资源；保留脚本引用路径与资源的对应关系。
- 原作该片段的操作步骤及可运行参照，或覆盖两条路线的录屏/截图与预期结果。对照后续行为，不能只对齐首帧。
- 有多语言、特殊文本框/菜单、并行演出或跨章调用时保留代表片段，用来暴露通用接口缺口。

原版存档互通另行增加：同一版本下的一份槽位、关联global/system/附件，以及原作载入后继续操作的参照。第一轮网页从头播放实验可以不等这些材料，但不能因此声称原档兼容。

原始游戏/原档/录屏只放本地ignored tests/private/<作品标识>/，也可先提供仓库外的本机目录供只读调查；不复制进生产包或Git。可提交的转换器与回归测试位于tests/migration/<作品标识>/，通过公开SDK入口生成Program/protobuf并运行；生成载荷和运行结果放ignored目录。未收到资料前不创建空适配器冒充迁移完成。

执行顺序：静态清点版本/脚本/资源 → 记录源指令到SDK的映射与unsupported清单 → 建真实转换器/资源适配 → 打包SDK的独立测试项目运行 → 原作两路线、保存/刷新继续和资源请求对照。通用能力缺口补回SDK；作品语法和位置映射留在测试适配器，Core不按gameId特判。若需扩展公共语义，仍先写有限支持集与ADR。

当前仍缺：I1-01国际化；W1-03B2高级能力模块/恢复闭包；W1-03C热记录/留存/容量；W1-04发布缓存/离线/目标平台；真实脚本转换与原档继续参照。单体路径的高级功能已有有限实现，不能把模块模式的unsupported误写成所有路径都缺失。小章节能验证语义适配，完整规模与弱网/设备验收仍需后续代表性数据。

## 两部目标作品与发行认证

| 输入 | 对应任务 | 取得后用于 |
| --- | --- | --- |
| 《水仙》具体 edition、语言、补丁及可复现指纹 | N-01 | 选择真正 codec/方言/位置与加载规则 |
| 《海市蜃楼之馆》同类版本信息 | F-01 | 区分发行渠道/补丁和存档包依赖 |
| 已可读取素材和已知行为/脚本或人工重建依据 | N/F | 标准 Program 与资源目录，不让 Core 处理未知保护 |
| 合法保存点的槽位与相关 global/system/附件 | N-01/F-01 | 调查真实字段和依赖，不按扩展名猜格式 |
| 原版加载后继续操作的截图/录屏/记录/可运行参照 | N-02/F-02 | 对照后续变量/分支/权限/表现，不能只看载入截图 |
| 特殊菜单、历史、调用、计时、音频等代表样本 | N-02/F-02 | 早期检验边界与必要扩展 |
| 目标桌面/移动浏览器和可取得真机 | M5-03 | 固定平台声明与实际验证范围 |
| 是否要求最终首版双向原档互通 | N/F 报告 | 当前硬要求为原版→网页；反向独立认证 |

原版保护或专有格式未知时，准确记录需要可解析输入/依据，既不承诺破解，也不把这项成本隐藏成“只是一个 codec”。

公开包名、项目许可证、远程发布位置在实际准备公开发行时核对现有仓库/用户选择；当前可以交付本地包，不擅自占用名称或发布。
