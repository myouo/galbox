# 产品目标与完成定义

状态：产品目标规格；当前实现和验收状态见 tasks.json 与 evidence/。完整依据：[v0.6](reference/GalBox-SDK-v0.6-Implementation-Design.md)。

## 1. 最终产品

galbox-sdk 为准备移植桌面视觉小说的开发者提供一个强类型、可嵌入的 Web 运行与兼容 SDK。接收已明确的程序和资源，承担播放、交互、保存恢复、已知原版存档适配、诊断和静态发布的完整流程。

“薄”表示聚焦视觉小说移植和明确支持集；“完整”表示一个作品能实际运行、保存、恢复、调试和交付。默认 Player 降低接入成本，低层公开接口允许替换 UI、资源来源和作品扩展。

用户进一步明确完整通用 GalGame 功能目标，详见 [COMMON_VN](COMMON_VN.md)：正文/文字效果/文本框、舞台/媒体、图文存读档、系统设置/输入/自动快进、流程图、鉴赏与剧本 UI 都应由 SDK 提供通用实现。实例声明内容、资源、皮肤与策略，不承担重复建设这些系统的职责。M0–M5/H1 的历史完成仅代表有限 alpha 支持集；G0–G7 未完成前不得将其称为“常用功能齐全”。真实两作认证是另一条独立门槛。

## 2. 标准输入

| 输入 | 内容 | 必需性 |
| --- | --- | --- |
| GameBundle | 作品身份、版本、发布闭包、能力、配置 | 必需 |
| Program | 已表达的剧情、值、调用、演出和交互 | 必需 |
| AssetProvider/目录 | 已可使用的图片、声音、字体等及逻辑映射 | 必需 |
| CompatibilityBinding | 原版身份、codec、mapping、加载规则、证据与支持范围 | 声明原档兼容时必需 |

资源可读不等于剧情已移植。标准 Program 可以手写、由 Builder 产生或由独立转换器输出；SDK 不要求用户必须走某个旧引擎转换流程。

## 3. 明确的能力边界

Core 只认识标准 Program/状态/操作。未知加密、原安装包自动破解、通用旧语言解释、任意原生插件堆恢复不纳入主线。可选上游工具处理有依据的资源和脚本格式；SaveBridge 同样只处理已知存档格式或已准备中间数据。

不建设面向新手的剧情 IDE，不先建设云账号/多人同步/插件市场。不为可能的未来 WASM 维护第二个解释器。自研控制权落实在执行、状态、生命周期和扩展接口，现成图形、媒体和构建库负责底层设施。

## 4. 两部作品的目标

《水仙》与《海市蜃楼之馆》分别锁定发行版、语言和补丁后，原版→网页导入是最终支持版的验收要求。需要验证加载后的状态和后续行为；只有截图相似或能读文件不算兼容。

目前未取得对应真实 Program/资源/原档/原作参照。任务表保留资料阻塞，不编造格式、不用合成 JSON 冒充真实原档。导出接口可以按实际需要建设，网页→原版只有在原版程序中加载并继续验证后才开放相应范围。

## 5. 完成的可观察结果

| 交付状态 | 必须成立 |
| --- | --- |
| M2 初始引擎 | 原创样例真实运行，控制流/任务/内部存档/普通进度闭合，打包消费者可接入 |
| M3–M5 SDK alpha | 有状态扩展和迁移、合成 SaveBridge、CLI/模板、设备与故障验证、公开能力报告 |
| M6 最终两作支持版 | N/F 明确版本和范围通过真实原档导入/继续对照；SDK 可被第三方系统化使用 |

最终工程交付包括可构建源码、锁文件、SDK 类型/构建产物、Player、CLI、原创公开 fixtures、开发文档、能力/兼容报告和可复跑验证。运行时输出、原版证据和源码许可按实际来源分别管理。外部托管、npm 发布或 Git 推送不是仅凭此任务包自动执行的动作。

设备兼容性按用户实际问题补充：同一 Pixi 图像舞台支持 WebGL2 优先与 Canvas2D 后备，见 GRAPHICS.md/ADR0021。设备选择不改变剧情/存档，当前 Canvas 未对等的滤镜/隔离转场明确拒绝并由 H2-02 保留，完整 G7 不得略过。
