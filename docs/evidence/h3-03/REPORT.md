资源屏障继续冻结剧情时钟、输入、保存和未提交效果，默认保持已有音频；显式 resourceAudio=pause 保留同步冻结策略。滚动窗口接续未完成预取；版本音频的首个声部独占接走已准备元素，第二声部保留独立播放头。缓存淘汰/销毁释放未消费设备，活动设备由播放源清理，HTTP 版本重验与取消仍有效。编码字节和 1 MiB 预留计入流音频估算；这不是浏览器内部缓存/解码器总 RAM 上限。
