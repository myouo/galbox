# Compressed cold records and separate disk inventory (W1-03C1)

2026-11-01. ADR0102–0103. Real illustrated slots reached the old aggregate budget before forty saves. Compression alone still rejects create28 with hot=1747383 JSON characters and cold=2235368 bytes. Layout v3 therefore declares 64MiB compressed cold inventory separately from 4M actual hot root (including directory), per-record decoded/stored and scoped decoded/summary working limits. Portable/wire limits remain unchanged. Gzip preserves Unicode and finite signed zero, validates lengths/CRC and bounded expansion, and never drops previous cuts/history/receipts. This completes W1-03C1, not W1-03C hot-root/retention/large-export work.

Codec work runs outside transactions. A final readwrite root-generation CAS publishes records/summaries/deletions/root atomically, with finite retries. v2 migration also rechecks old cold bytes inside that transaction, preserving equal-sized concurrent old-writer updates. Old monolithic/v2 stores upgrade only on a successful write. v3 hot-only operations retain single-transaction isolated I/O. Older binaries cannot write v3; cold writes require native gzip streams.
