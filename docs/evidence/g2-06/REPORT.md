# G2-06：ADV整页适配

2026-10-30，用户反馈长页出现滚动条。默认DOM renderer先以完整正文测量，再在溢出时用12步有界字号因子搜索；短页保留作者字号，逐字显现复用排版，普通文本保留隐藏尾部的几何空间，长词可换行。窗口尺寸/主题/字体/字号偏好变化会重新测量。显式NVL仍按原支持集滚动。

本改动只影响显示，不改Core分页、确认次数、Program/release或存档签名，不裁剪正文或插入新剧情页。原矩形过小仍不能保证可读字号；竖排/原生禁则/逐像素对照另验。

SDK build、371单元通过；相关浏览器分批10项通过（layout/text/window-opacity原8项、新2项）。新测试覆盖长CJK/Latin/不可断词、ruby、作者相对字号、1.5字号偏好、未显现尾部、缩放、图文保存/恢复与短页恢复原字号。初版新夹具暂停了Player而未解除暂停就发送输入，导致两项推进断言失败；夹具按公开暂停/输入接口修正后通过，没有放松产品断言。

SDK最终`pnpm check`通过；独立实包/真实内容验收继续记录；原始日志在独立实例ignored artifacts/text-fit，SDK没有真实作品数据。

真实字体几何探测另发现font box可伸到首行上方，而scrollHeight仍未溢出；后续修复在未变换布局坐标中检查字形框并预留缺失leading，避免只隐藏滚动条后切掉字形。新增对应原创字号/紧行距反例，相关11浏览器通过；实例探测也修正了将同一正文页内确认prompt误计为新页的夹具计数。进一步check/打包及八语验收继续。

首轮八语50638页几何通过后，发现西文极端缩排来自pre-wrap的悬挂换行空格：其inline box越界但没有可见笔画。后续测量只对该类未加下划线的空白排除字形框，仍保留原文字/换行与scroll尺寸，新增原创长词+悬挂空格反例。重新验收本修正，不能沿用较保守版本的字号统计。

悬挂空白修正的12相关浏览器与371单元通过。并行启动check与单元里的生成器子进程曾令只读生成检查观察到瞬时wire漂移；改为等待单元结束后顺序重验check，保留真实失败日志，不改Schema或检查条件。

悬挂空白版的日语探测发现空白首行在缩排时重新换行：只按原字号缓存leading可导致极端微缩。最终改为每个候选字号重新测量leading，新增空白首行换行反例；实例几何验收增加本作字号因子至少0.5的门槛，避免把不可阅读的微缩记作通过。先前几何通过不作为最终可读性认证。

逐候选leading修正已通过13相关浏览器、371单元及单元结束后的顺序`pnpm check`。下一实际tarball和八语完整几何/可读性验收。
